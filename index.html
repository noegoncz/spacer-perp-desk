Bybit connection

Enter a read-only API key. The key and secret are stored on this phone only, are never sent anywhere else and are not in the repository. Requests are signed on the device itself.

How to create a read-only key on Bybit
  1. Bybit → profile → API → Create New Key.
  2. Choose System-generated API Keys.
  3. Permissions: read-only, tick Positions (and Orders for the chart).
  4. Leave trading and withdrawals unticked.
  5. Leave the IP restriction empty — mobile networks change IP.
