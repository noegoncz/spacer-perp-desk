Připojení k Bybitu

Zadej read-only API klíč. Klíč i secret se ukládají pouze do paměti tohoto telefonu, nikam se neodesílají a nejsou v repozitáři. Podpis požadavků se počítá přímo v zařízení.

Jak vytvořit read-only klíč na Bybitu
  1. Bybit → profil → API → Create New Key.
  2. Zvol System-generated API Keys.
  3. Oprávnění: jen pro čtení, zaškrtni Positions (a Orders kvůli dalšímu checkpointu).
  4. Obchodování a výběry nezaškrtávej.
  5. IP omezení nech prázdné — mobilní síť mění IP adresu.
